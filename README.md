# Food Waste Predictor

## Overview
A mini project to predict food waste in university cafeterias based on historical preparation and serving patterns.

## Dataset
Includes mock records of meals prepared, served, and leftover waste for two cafeterias.

## Features
- CSV-based input
- Trains a linear regression model
- Predicts expected food waste based on planned meals

## Instructions
1. Install scikit-learn, pandas, and joblib
2. Run `python train_model.py` to train and save the model
3. Extend the notebook to use the model for real-time predictions
